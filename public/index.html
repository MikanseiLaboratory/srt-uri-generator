SRT URI

host / port / mode / latency / passphrase から、ブラウザ内だけで URI を生成します。パスフレーズはサーバーへ送信しません。

10〜79文字です。空の場合は暗号化しません。pbkeylen はパスフレーズがあるときだけ URI に追加されます。入力内容はこの端末の外部へ送信されません。

その他のオプション

URI

クエリの値は encodeURIComponent でエンコードしています。OBS と FFmpeg の latency はマイクロ秒、srt-live-transmit と vMix はミリ秒です。listener で host を空にすると srt://:port?mode=listener になります。

FFmpeg と同じ URI です。この URI の latency はマイクロ秒です。2000 ms は latency=2000000 になります。

受信は ffmpeg -i "URI"、送出は -f mpegts "URI" を使用します。latency はマイクロ秒、connect_timeout はミリ秒のままです。

latency はミリ秒です。パラメータ名は SRTO_ を除いたもの（enforcedencryption, conntimeo, payloadsize）になります。

パスフレーズと streamid はパーセントエンコードしません。Type は Caller / Listener / Rendezvous、Latency はミリ秒です。
