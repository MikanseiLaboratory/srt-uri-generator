SRT URI Generator

OBS Studio、FFmpeg、srt-live-transmit、vMix、MediaMTX 用の SRT URI をブラウザ内で生成します。入力内容は外部に送信されません。

入力

接続

IPv4、ホスト名、IPv6（[2001:db8::1]）。host:port を貼り付けると port も埋まります。

mode

listener 側へ接続します。送出側で一般的な設定です。

ミリ秒で入力します。OBS と FFmpeg の URI ではマイクロ秒に変換します（2000 ms → latency=2000000）。

暗号化

10〜79 文字。空欄なら暗号化しません。

パスフレーズがあるときだけ URI に付きます。

ストリーム

最大 512 文字。アクセス制御の標準形式の例: #!::r=live,m=publish
